# Sleeve Notes for the Frog Trio — "Still Water"

My entry for the make.fun **u-ravendell-sleeve-notes-for-the-frog-trio-29d80da5** competition:
one album title and a short back cover blurb (361 characters in total) for a
jazz trio made entirely of frogs, written the way a record shop owner who
has actually heard the trio play would write it.

`main.ts` writes the sleeve text to `entry.txt` in the output directory so
the sealed scorer can read it. It does no fetching, no scoring, no network.
